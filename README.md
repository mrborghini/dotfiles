# dotfiles

## Installation

1. Clone the repository

```bash
git clone https://github.com/mrborghini/dotfiles.git
```

2. Run the installation script

```bash
./install.sh
```

## Current dotfiles

| File                     | Description             |
| ------------------------ | ----------------------- |
| .zshrc                   | Zsh configuration file  |
| .config/fish/config.fish | Fish configuration file |
